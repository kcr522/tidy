# 스크랩: 공유받기 · 링크 미리보기 · 캡처 · AI 정리

이 문서는 서버나 폰 앱 빌드가 있어야 완전히 되는 부분을 쉽게 정리한 것이에요.

## 1. 인스타그램 · 네이버 · X 에서 "공유 → Tidy"

| 어디서 | 지금 되는가 | 필요한 것 |
| --- | --- | --- |
| 안드로이드 (크롬으로 Tidy를 "앱 설치") | ✅ 됨 | 설치만 하면 공유 목록에 Tidy가 떠요 (PWA `share_target`) |
| 아이폰 (사파리 홈 화면 추가) | ❌ 안 됨 | 애플이 웹앱 공유받기를 막아 둠 → 폰 앱 필요 |
| 컴퓨터 | 해당 없음 | 링크 복사 → 붙여 넣기 |
| 폰 앱 (Capacitor) | 아직 | 아래 "폰 앱에 붙이는 법" |

공유로 들어온 주소는 `/share?title=…&text=…&url=…` 로 열리고, 글 안에서 주소를 찾아 저장 창을 띄워요.
같은 곳(인스타그램 등)에서 온 링크는 지난번에 고른 카테고리를 미리 골라 둬요.

### 폰 앱에 붙이는 법 (나중에)

- **안드로이드**: `android/app/src/main/AndroidManifest.xml` 의 MainActivity 에 `ACTION_SEND` (`text/plain`, `image/*`) intent-filter 를 넣고,
  공유받은 값을 웹 화면으로 넘겨 주는 플러그인(예: `@capgo/capacitor-share-target`)을 설치해서 받은 주소로 `/share?text=…` 를 열면 돼요.
- **아이폰**: Xcode 에서 "Share Extension" 타깃을 하나 더 만들고, App Group 으로 본 앱과 값을 나눠야 해요. 맥과 Xcode, 애플 개발자 계정이 필요해요.

## 2. 링크 미리보기 (썸네일 · 제목)

브라우저는 보안 규칙(CORS) 때문에 다른 사이트의 HTML 을 직접 못 읽어요. 그래서 작은 서버 함수가 대신 읽어요.

- 배포: `api/preview.ts` (Vercel 함수, 따로 설정할 것 없음)
- 개발 중: `npm run dev` 에 같은 기능이 들어 있음 (`vite.config.ts`)
- 폰 앱: 앱이 직접 읽어요 (CapacitorHttp, CORS 없음)

썸네일은 저장할 때 받아서 기기에 넣어 둬요. 인스타그램 이미지 주소는 며칠 뒤 만료되기 때문이에요.
인스타그램·X 가 미리보기 봇을 막으면 제목이 안 나올 수 있어요. 그래도 링크는 저장돼요.

## 3. 인스타그램 동영상

동영상 파일을 내려받는 건 인스타그램 규칙 위반이라 하지 않아요. 대신:

- 자세히 화면에서 **인스타그램 공식 퍼가기(embed) 플레이어로 앱 안에서 재생**해요 (유튜브도 같음).
- 게시물이 지워질 때를 대비해 **내가 찍은 화면 녹화 영상**을 캡처처럼 같이 저장할 수 있어요 (80MB까지).

## 4. 캡처 같이 저장 · 사진 편집

- 새 링크를 저장하면 "캡처본도 같이 저장할까요?" 창이 떠요. 설정 > 스크랩 에서 끌 수 있어요.
- 사진 편집(자르기, 돌리기, 그리기, 글자)은 기기 안에서만 해요. 처음 편집할 때 원본을 따로 남겨서 "원본으로" 되돌릴 수 있어요.
- 캡처와 썸네일도 백업 파일에 들어가요 (그래서 백업 파일이 커질 수 있어요).

## 5. AI 정리 버튼

카드의 동그란 AI 버튼 → 설정 > AI 연결 에서 고른 방법을 그대로 써요.

- 기본(AI 없이): 미리보기 설명(인스타 캡션)을 줄여서 보여 줘요.
- Tidy AI (서버의 무료 Gemini 키) 또는 내 Gemini 키: 제목·캡션·메모와 **첫 캡처 사진**을 같이 읽고 정리해요. 게시물이 지워졌어도 캡처로 정리할 수 있어요.
- 연결이 실패하면 기본 정리로 대신 넣어요.
