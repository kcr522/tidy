## 1. 한눈에 보기

**Tidy**는 가계부 · 할 일 · 스크랩을 한 앱에 모은 개인용 생활 정리 앱입니다. 하나의 코드로 폰 앱, 컴퓨터 앱(PWA 설치), 폰 웹, 컴퓨터 웹 네 곳에서 돌아갑니다.

| 구분 | 지금 상태 |
|---|---|
| 1차 MVP (가계부 · 할 일 · 스크랩 · 대시보드 · 백업) | ✅ 완성 |
| 2차 (캘린더 · 일기 · 습관 · 적금 · AI 비서 · 캡처 입력 · 로그인과 동기화) | ✅ 완성 |
| 3차 (앱 잠금 · 위젯 · 반복 할 일 · 예산 · 자동 백업 · 월간 리포트 · 구글 캘린더) | ✅ 7가지 모두 완성 |
| 다듬기 (캘린더 개편, 스크랩 자동 캡처, 일기 자동 저장, 분할 화면 등) | ✅ 계속 진행 중 |
| 합친 PR | 78개 중 **77개 합침**, 1개 검토 중 (#68) |
| 실제 폰에서 아직 확인 못 한 것 | 지문 잠금, 백업 고친 것, 분할 화면, 음식 사진 기록 등 ([5-2](#5-2-만들었지만-실제-폰에서-아직-확인-못-한-것)) |
| 남은 일 · 정할 일 | 구글 캘린더 양방향 마무리, 플레이 스토어 방식 선택 ([5-3](#5-3-열려-있거나-막힌-일), [5-4](#5-4-정해야-하는-것)) |

## 2. 만든 과정

모든 작업은 2026년 11월 10일부터 시작했고, 기능마다 브랜치를 따서 PR을 열고 합치는 방식으로 진행했습니다.

### 2-1. 기획 (11월 10일)

- 학교 서버와 상관없이 **내가 실제로 쓰려고** 만드는 앱으로 시작했습니다. 처음에는 서버 없이 기기 안 DB에만 저장하는 것이 원칙이었습니다.
- 요구사항 분석서와 시스템 설계서(7일 스프린트)를 쓰고, Spec Kit 형식으로 헌법 · 명세 · 계획 · 데이터 모델 · 작업 목록을 정리했습니다. **PR #1**
- 바로 이어서 2차 요구사항(캘린더, 구글 로그인, AI 캡처 입력)도 문서로 정리했습니다. **PR #2**
- 기술 선택: React + TypeScript + Vite + Tailwind, 저장은 IndexedDB(Dexie), 컴퓨터 앱은 Tauri/Electron 대신 **PWA 설치**, 폰 앱은 **Capacitor**.

### 2-3. 2차 — 매일 쓰는 생활 앱으로 (11월 10일 ~ 11월 13일)

1차의 세 기능을 매일 쓰는 앱으로 키웠습니다. 여러 PR을 동시에 만들고 `preview/all-features` 브랜치에 모아 합쳤습니다. DB 버전 번호가 겹치는 문제는 합칠 때 순서대로 다시 매겼습니다.

- **가계부 확장**: 가게 로고, 시간 · 결제 수단, 정기 내역과 월급 D-day, 모르는 결제처 물어보기, 차트 · 통계 · 고정 금액, 가계부 달력 (#12 ~ #18)
- **새 기능**: 캘린더 · 일기 (#18), 습관 (#22), 적금 (#24), 다크 모드와 꾸미기 (#19)
- **AI**: AI 소비 한마디 (#20), AI 비서 (#25), 음식 사진 기록 (#21, #27), 은행 캡처 입력은 무료 기기 안 글자 인식 (#26)
- **스크랩 업그레이드**: 카테고리, 공유받기, 미리보기, 캡처 · 사진 편집, AI 요약 (#23)
- **AI 비용 결정**: 유료 Claude API는 쓰지 않기로 하고, 무료 Gemini → 무료 Groq → 기본(규칙) 모드 순서로 바꿨습니다 (#28 ~ #30, #34, #35, #63)
- **안드로이드 앱**: GitHub Actions로 APK 자동 빌드, 고정 키로 서명해서 지우지 않고 덮어 깔기 (#26, #32)
- **로그인과 동기화**: 구글 로그인 + Firebase(무료) 동기화, 로그인 없이 쓰기도 가능 (#49, #51, #54, #55)
- **웹 배포**: Vercel 무료 요금제에 올림 (https://tidy-gules.vercel.app)
- 11월 13일, `preview/all-features`의 2차 기능 전체를 `main`에 합쳤습니다 (#60).

### 2-5. 다듬기와 고치기 (11월 11일 ~ 11월 14일)

실제로 쓰면서 나온 요청과 문제를 하나씩 고쳤습니다.

- **속도**: AI 답변과 첫 로딩 빠르게 (대시보드 4G 기준 3.0초 → 2.1초) (#52)
- **AI 정확도**: 기본 모드 정확도 시험 도구와 개선 (21개 중 17개 맞음) (#53), 키 입력 없이 쓰는 Tidy AI 서버 (#61), 질문은 AI 없이 내 기록에서 바로 답하기 (#64), Groq 404 오류 (#71)
- **로고와 시작 화면**: 네칸 유리 타일 로고 + 개인정보 처리방침 페이지 (#56), 기본 시작 화면 (#50), 시작 화면 아이콘 빼기 (#70)
- **캘린더**: 일기 달력 (#58), 첨부 파일 (#57), 줄바꿈 · 공휴일 · 색 21가지 · 스티커 (#62), 화면 꽉 채우기 (#67), 일정만 보이게 (#74)
- **앱 업데이트**: 앱 안에서 새 버전 알림과 자동 설치 (#59)
- **스크랩**: 사이트 자동 캡처 + AI가 글 · 사진 읽기 (#69), 인스타 · X 공유 (#72), 캡션 길게 (#73)
- **일기 자동 저장** (#75), **일정하지 않은 월급** (#76), **분할 화면 대응** (#77), **습관 이모티콘 고르기** (#78)

## 3. 기술 구성

| 영역 | 쓰는 것 |
|---|---|
| 화면 | React 19, TypeScript, Vite, Tailwind, Pretendard 글꼴, Lucide 아이콘 |
| 저장 | IndexedDB + Dexie (기기 안). 로그인하면 Firestore와 동기화 |
| 로그인 · 동기화 | Firebase (프로젝트 `tidy-b0d8d`, 무료 Spark, Firestore 서울 리전), 구글 로그인만 |
| 웹 · 서버 함수 | Vercel 무료 (팀 `tidy14`). `api/` 폴더: 미리보기, AI, 구글 캘린더, 앱 업데이트 등 |
| 폰 앱 | Capacitor 8 (안드로이드 APK는 GitHub Actions가 빌드해서 Releases에 올림) |
| 컴퓨터 앱 | PWA 설치 (Tauri · Electron 안 씀) |
| AI | 무료만: Gemini → Groq → 기본(규칙) 모드. 은행 캡처는 기기 안 글자 인식(tesseract.js) |
| 직접 만든 안드로이드 플러그인 | 지문(BiometricPlugin), 구글 인증(GoogleAuthPlugin), 앱 업데이트(AppUpdatePlugin), 홈 위젯, 캡처 |
