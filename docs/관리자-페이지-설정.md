# 관리자 페이지 켜기

Tidy 관리자 페이지(`/admin`, 설정 > **관리자 페이지**)는 주인 계정에서만 보여요.
사용자 목록, 사람별 Tidy AI 사용량(오늘 / 하루 한도, 최근 7일), 웹 버전 · 최신 앱 버전 · 서버 키 상태를 한곳에서 봐요.
일기 · 가계부 · 메모 같은 **내용은 읽지 않고**, 언제 썼는지와 개수만 셉니다.

모두 무료예요 (Firebase Spark · Vercel Hobby 그대로).

## 1. 관리자 메일 넣기

1. Vercel → **tidy** 프로젝트 → **Settings** → **Environment Variables**
2. 이름 `ADMIN_EMAILS`, 값은 관리자로 쓸 **구글 메일** (여러 개면 쉼표로)
3. Environment는 Production · Preview 둘 다 체크

## 2. Firebase 서비스 계정 넣기

모든 사람의 목록을 읽으려면 서버에 Firebase 관리자 열쇠(서비스 계정)가 필요해요. 이 열쇠는 Vercel 서버에만 있고 앱에는 절대 들어가지 않아요.

1. [Firebase 콘솔](https://console.firebase.google.com/) → **TIDY** 프로젝트 → 톱니 ⚙️ **프로젝트 설정** → **서비스 계정** 탭
2. **새 비공개 키 생성** → **키 생성** → JSON 파일이 받아져요
3. Vercel 환경 변수에 이름 `FIREBASE_SERVICE_ACCOUNT`, 값은 그 JSON 파일 내용을 **통째로** 붙여 넣기
4. 받은 JSON 파일은 다른 곳에 올리지 말고 지워 주세요 (필요하면 다시 만들 수 있어요)

## 3. 다시 배포

Vercel → **Deployments** → 맨 위 배포의 `⋯` → **Redeploy**.
그다음 Tidy에 관리자 메일로 로그인하면 설정에 **관리자 페이지** 칸이 생겨요.

## 어떻게 지켜지나요

- 관리자인지는 서버(`api/admin.ts`)가 정해요. 구글 로그인 토큰을 구글에 확인하고, 인증된 메일이 `ADMIN_EMAILS`에 있을 때만 정보를 줘요. 화면에서 칸을 숨기는 것만으로 막는 게 아니에요.
- 다른 사람이 `/admin` 주소를 직접 열어도 "관리자만 볼 수 있어요"만 보여요.
- Firestore 보안 규칙(본인 기록만 읽고 쓰기)은 그대로예요.
