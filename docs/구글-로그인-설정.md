# 구글 로그인 + 기기 동기화 켜는 방법

Tidy 코드는 다 들어가 있어요. Firebase(구글의 무료 클라우드)에 프로젝트를 한 번 만들어 주면 켜져요.
**돈은 들지 않아요** (Spark 무료 요금제, 카드 등록 없음). 10명이 매일 써도 무료 한도(하루 읽기 5만 번, 쓰기 2만 번, 저장 1GB)를 넘지 않아요.

> 시간: 10분쯤. 컴퓨터에서 하는 게 편해요.

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **"Firebase 프로젝트 만들기"** (또는 "프로젝트 추가")를 눌러요.
3. 이름 칸 아래 **"기존 Google Cloud 프로젝트에 Firebase 추가"** 를 눌러서 **Creat** 프로젝트를 골라요.
   (구글 캘린더 연결 때 만든 프로젝트예요. 갤럭시 앱 등록이 이미 돼 있어서 이걸 쓰면 편해요)
4. Google 애널리틱스는 **끄고** 만들기를 눌러요.

## 2. 구글 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**.
2. **로그인 방법** 탭 → **Google** → **사용 설정** 켜기 → 지원 이메일에 내 이메일 고르기 → **저장**.
3. 저장한 뒤 **Google** 을 다시 눌러서 **"웹 SDK 구성"** 을 펼치면 나오는 **웹 클라이언트 ID** (`…apps.googleusercontent.com` 으로 끝나는 값)를 복사해 둬요.
4. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `tidy-gules.vercel.app` 넣고 추가.

## 3. 데이터 저장소(Firestore) 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)** → 다음 → **프로덕션 모드** → 만들기.
3. 위쪽 **규칙** 탭을 눌러서 있던 내용을 지우고 아래를 그대로 붙여 넣은 뒤 **게시**.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

이 규칙 덕분에 로그인한 사람은 **자기 기록만** 읽고 쓸 수 있어요. 친구가 같이 써도 서로의 기록은 못 봐요.

## 4. 웹 앱 등록하고 설정 값 받기

1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → **일반** 탭 아래 **내 앱** → **`</>`(웹)** 아이콘.
2. 앱 닉네임 `Tidy 웹` → **앱 등록** (Firebase 호스팅은 체크하지 않아요).
3. 화면에 나오는 `const firebaseConfig = { … }` 부분을 복사해요.

## 5. Claude 에게 보내기

아래 두 가지를 채팅에 붙여 주세요. 둘 다 **비밀번호가 아니라 공개돼도 괜찮은 값**이에요 (데이터는 3번의 규칙이 지켜요).

- 4번의 `firebaseConfig` 내용 (apiKey, authDomain, projectId, appId …)
- 2번의 웹 클라이언트 ID

Claude 가 코드(`src/lib/firebaseConfig.ts`)에 넣으면 웹 사이트와 갤럭시 앱 둘 다 저절로 로그인 화면이 생겨요.
(직접 하려면 그 파일의 빈칸에 붙여 넣거나, Vercel 환경 변수 `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID`, `VITE_GOOGLE_WEB_CLIENT_ID` 로 넣어도 돼요)

## 갤럭시 앱 로그인

갤럭시 앱은 **TIDY(Firebase) 프로젝트**에 Android 클라이언트로 등록해요. 같은 앱(패키지 + SHA-1)은 한 구글 클라우드 프로젝트에만 등록할 수 있어서,
다른 프로젝트(예: Creat)에 같은 등록이 있으면 먼저 지워야 해요 (지운 것은 30일 안에 "삭제된 사용자 인증 정보 복원"으로 되살릴 수 있어요).

1. Google Cloud 에서 다른 프로젝트의 **Tidy Android 클라이언트**를 지워요 (Creat → API 및 서비스 → 사용자 인증 정보).
2. Firebase **프로젝트 설정 → 일반 → 내 앱 → Android 앱 추가** (이미 있으면 그 앱의 **디지털 지문 추가**)
   - 패키지 이름: `com.kcr522.tidy`
   - SHA-1: `C9:91:AA:50:3D:6C:70:AA:52:A3:F0:A4:13:3F:03:5F:25:87:92:1E`
   (google-services.json 파일은 받지 않아도 돼요)
3. 구글 캘린더로 보내기를 쓰려면 TIDY 프로젝트에서 **Google Calendar API** 를 사용 설정해요:
   https://console.cloud.google.com/apis/library/calendar-json.googleapis.com?project=tidy-b0d8d
4. 구글 로그인 화면에 뜨는 이름은 TIDY 프로젝트 **OAuth 동의 화면 → 브랜딩 → 앱 이름** 이에요.

코드는 `src/lib/firebaseConfig.ts` 의 `nativeSignInClientId` (TIDY 웹 클라이언트 ID).

## 어떻게 동작하나요

- 처음 켜면 **로그인 화면**이 나와요. "Google로 계속하기" 또는 "로그인 없이 이 기기에서만 쓰기".
- 로그인하면 이 기기 기록이 클라우드에 올라가고, 같은 계정으로 로그인한 폰·컴퓨터와 **저절로 맞춰져요** (몇 초 안에).
- 인터넷이 없을 때 쓴 것은 기기에 저장해 뒀다가 연결되면 올려요.
- 일기 사진, 스크랩 캡처 사진도 같이 맞춰져요. 1MB 가 넘는 파일(화면 녹화 영상 등)은 찍은 기기에만 있어요.
- 화면 꾸미기, 잠금 비밀번호, AI 키는 기기마다 따로예요.
- 로그아웃해도 클라우드 기록은 남아 있어서 다시 로그인하면 받을 수 있어요.
- 이미 기록이 있는 기기에서 처음 로그인하면 "클라우드 기록 쓰기 / 이 기기 기록 쓰기" 중 하나를 골라요.
