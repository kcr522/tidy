## 2. 고친 것 자세히

### 2-1. AI 횟수를 앱이 못 고치게 (Firestore 규칙 + 서버)

- **전**: 서버가 그 사람 로그인 토큰으로 `users/{uid}/aiUsage/{날짜}` 에 횟수를 썼어요. 규칙이 "내 자리는 마음대로"라서, 그 계정으로 로그인한 사람(가입만 하면 누구나)이 Firestore에 직접 `count: 0` 을 쓰면 하루 제한이 없어졌어요.
- **후**:
  - [firestore.rules](../firestore.rules): `aiUsage` 는 본인도 **읽기만**. 나머지(`rows` · `files` · `meta` · `route`)는 그대로.
  - [src/lib/ai/proxyServer.ts](../src/lib/ai/proxyServer.ts): 횟수는 **서비스 계정**(`FIREBASE_SERVICE_ACCOUNT`, 관리자 페이지에 쓰던 것)으로 씀. 횟수를 세지 못하면 AI를 부르지 않고 "잠시 뒤에 다시" 라고 답함.
  - 확인: `npm run test:rules` (에뮬레이터 13가지). 옛 규칙으로 돌리면 "aiUsage 쓰기 · 지우기" 2개가 **허용**되어 빨간불, 새 규칙은 13개 모두 통과.

### 2-2. 허용 메일은 인증된 메일만

이메일 가입은 아무 메일이나 적을 수 있어서, `AI_ALLOWED_EMAILS` 에 있는 메일로 가입만 하면 통과됐어요. 이제 구글이 **인증한 메일**일 때만 통과하고, 사용 중지한 계정은 막아요.

### 2-3. 미리보기 서버가 안쪽 주소를 못 읽게 (SSRF)

[src/lib/scrap/previewServer.ts](../src/lib/scrap/previewServer.ts) 가 읽기 전에 **DNS로 실제 IP를 찾아** 사설망 · 이 컴퓨터 · 클라우드 내부(169.254.169.254) · 통신사 공유망(100.64/10) · IPv6 안에 숨긴 IPv4 를 막아요. 리다이렉트도 한 번마다 다시 확인해요.

### 2-4. 웹 CSP

[vercel.json](../vercel.json) 에 `Content-Security-Policy` 를 넣었어요.
- 스크립트: Tidy 자신 + 구글 로그인(`apis.google.com`, `accounts.google.com`, `www.gstatic.com`) + `index.html` 의 화면 밝기 스크립트(sha256 지문)만. 글자 인식(OCR)용 `wasm-unsafe-eval`.
- 퍼가기 창: Firebase 로그인 · 구글 · 인스타그램 · X · 유튜브만.
- `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, http → https 로 올리기.
- 사진(`img-src`)과 서버 연결(`connect-src`)은 스크랩 썸네일 · AI · 날씨 때문에 https 전체를 열어 뒀어요.
- `index.html` 안 스크립트를 고치면 지문이 바뀌어 화면이 안 뜰 수 있어요. `tests/unit/securityHeaders.test.ts` 가 바로 빨간불로 알려 줘요.
- 확인: 배포와 같은 머리글로 `dist` 를 띄우고 대시보드 · 가계부 · 할 일 · 스크랩 · 달력 · 일기 · 메모 · 설정 · 리포트 · 습관 · 검색 · AI 비서를 열었을 때 막힌 것 0개. 일부러 넣은 남의 스크립트(`evil.example.com`)만 막힘.
- HSTS 는 1년 → 2년 + 하위 주소 포함.

### 2-5. 배포 APK 디버그 모드 끄기

GitHub Actions 는 `assembleDebug` 로 APK 를 만들어요(같은 열쇠로 서명해서 덮어 깔기 위해). 그래서 앱이 `debuggable` 이었고 Capacitor 가 웹뷰 디버깅도 켰어요.
[android/app/build.gradle](../android/app/build.gradle) 에 `debuggable false`, [capacitor.config.ts](../capacitor.config.ts) 에 `webContentsDebuggingEnabled: false` 를 넣었어요. **서명 열쇠는 그대로**라 업데이트는 지금처럼 덮어 깔려요.

## 3. 바꾸지 않은 것 (이유)

| 항목 | 왜 그대로 두나 |
|---|---|
| 저장소 안 서명 열쇠(`android/app/tidy-debug.keystore`, 비밀번호 `android`) | 열쇠를 바꾸면 폰에 깔린 Tidy 위에 덮어 깔리지 않아서 **지우고 다시 깔아야** 하고, 로그인 안 한 기기의 기록이 사라져요. 저장소가 비공개라 열쇠를 볼 수 있는 사람은 본인뿐이에요. **저장소를 공개로 바꾸지 않는 것**이 가장 중요해요. 스토어(Play Console)에 올리게 되면 그때 새 열쇠로 바꾸는 게 좋아요 |
| 안드로이드 `allowBackup="true"` | 구글 백업은 폰 잠금으로 암호화되고, 새 폰으로 옮길 때 기록을 살려 줘요. USB 로 꺼내는 길(adb backup)은 디버그를 끄면서 막혔어요 |
| `/api/preview` 로그인 없이 쓰기 | "로그인 없이 이 기기에서만 쓰기" 로도 스크랩 미리보기가 돼야 해서요. 내부 주소는 막았고, 공개 페이지만 읽어요 |
| IndexedDB 기록 암호화 | 폰 · 브라우저가 이미 기기 저장소를 암호화해요. 앱 잠금은 화면을 가리는 잠금이에요 |
