## 테스트 기록 쓰는 법

새 기능을 넣거나 테스트를 새로 쓰거나 고친 PR은 **같은 PR 안에서** 테스트 기록 한 장을 더해요.

1. [기록/양식.md](기록/양식.md)를 복사해 `기록/<날짜>-<기능 이름>.md` 로 만든다 (예: `2026-11-27-대시보드-새-위젯.md`).
2. 채우는 것: 무엇을 확인했나(테스트 제목 목록), 경계값 짝, 가짜로 바꾼 것, 일부러 망가뜨려 본 결과, 테스트로 못 본 것, 돌린 명령과 결과.
3. 아래 목록 맨 아래에 한 줄 더한다.
4. 테스트가 늘거나 파일이 늘면 [테스트 코드 정리](테스트-코드-정리.md)의 숫자 · 기능별 표도 맞춘다.
