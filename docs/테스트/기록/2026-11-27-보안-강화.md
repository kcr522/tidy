## 3. 가짜로 바꾼 것

- 구글 로그인 확인 · Firestore · Gemini · 서비스 계정 토큰 주소: 가짜 `fetch` (진짜 RSA 열쇠로 서명은 실제로 해 봄)
- DNS: `setHostResolver` 로 "이 이름은 127.0.0.1" 같은 답을 바꿔 끼움 (진짜 `fetch` 일 때만 실제 DNS 를 씀)
- Firestore 규칙: Firebase 에뮬레이터 (`demo-tidy`, 진짜 프로젝트에 닿지 않음)

## 4. 일부러 망가뜨려 보기

- `proxyServer.ts` 의 "세지 못하면 503" 줄 지움 → "횟수를 세지 못하면 … AI 를 부르지 않는다" 빨간불 → 되돌림
- `previewServer.ts` 의 `assertPublicHost` 부르기 지움 → "안쪽 IP(127.0.0.1)를 가리키면 읽지 않는다" 빨간불 → 되돌림
- `build.gradle` 의 `debuggable false` → `true` → "debug 판 APK 도 디버그 모드가 꺼져 있다" 빨간불 → 되돌림
- `firestore.rules` 를 옛 규칙으로 → "내 aiUsage 쓰기 · 지우기" 2가지가 허용되어 실패 2 → 새 규칙으로 되돌림

## 5. 테스트로 못 본 것

- CSP 를 건 실제 Vercel 배포: 같은 머리글로 `dist` 를 띄워 12개 화면을 열고 막힌 것 0개를 확인했지만, 샌드박스는 바깥 인터넷(구글 로그인 창 · 글꼴 CDN)이 막혀 있어서 그 부분은 배포 뒤 로그인 · 글꼴 바꾸기로 확인해야 해요
- 실제 폰에서 디버그가 꺼진 APK 업데이트가 덮어 깔리는지 (서명 열쇠는 같아서 될 것)
- 진짜 Firestore 에서 서비스 계정으로 횟수 세기 (Vercel 에 `FIREBASE_SERVICE_ACCOUNT` 가 이미 있음)
